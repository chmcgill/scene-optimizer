Scene Optimizer

A Blender add-on for large outdoor scenes. It hides what the camera can't see, swaps in lighter models as things get farther away, and includes a full grass and foliage scatter tool that does the same for every single clump of grass.

Problem

Big scenes waste most of their work on things nobody sees

Objects outside the shot, or hidden behind a hill, still cost memory and render time. Vegetation is worse. A meadow is hundreds of thousands of grass clumps, and in a scatter they all belong to one object, so the usual tools can only show or hide all of them at once. Distance doesn't help either: a clump 120 m away renders the same 5,000-triangle model as the one at your feet.

Approach

Two layers: whole objects, and every scattered instance

Objects · Python

Scene Optimizer

  • Frustum culling against the camera's planes, with margin and padding.
  • Occlusion culling: rays across each object's screen footprint, against a BVH of the occluders.
  • Distance LOD with hysteresis, live during playback and animation renders.
  • Non-destructive: Preview first, then Apply. Only visibility flags change, and Restore puts everything back.
Instances · Geometry Nodes

Scatter Systems

  • Each instance picks its LOD by camera distance, and far instances thin out with scale compensation and a soft fade.
  • Frustum test in camera space, and occlusion with one ray from the instance's top to the camera.
  • Tools for the look: patches, slope limits, paths kept clear, edge fade, tilt, lean and per-instance colour.
  • A preset library with rendered thumbnails.

Debugging

One switch shows every LOD in the viewport

  • Visualize LODs colours object LOD groups and every scatter system at once (LOD0 green, LOD1 yellow, LOD2 orange, LOD3 red, up to 8 levels). The overlay labels use the same colours.
  • Viewport only. Scatter systems switch to a coloured copy of each LOD mesh behind an Is Viewport node. Objects get a modifier that's switched off for render. Renders and mesh data are never touched.
  • Hide any level or asset to inspect it on its own, for example only the far LOD, or one grass variation. Hidden ones leave gaps, and nothing else moves.
How it works

One generated node tree per scatter system

1 · input

Surfaces

Terrain plus an optional collection of more ground meshes.

2 · points

Distribute

Random, or even spacing (Poisson disk) with a minimum distance.

3 · look

Shape

Mask, noise patches, soft slope, keep away from meshes and curves, edge fade.

4 · camera

Cull

Frustum, occlusion ray, max distance with fade, distance thinning.

5 · data

Attributes

so_random, so_dry, so_patch for materials.

6 · output

Instance

One pass per asset × LOD, picked by distance.

  • Every setting is a node-group input. Moving a slider changes one modifier value. The tree is rebuilt only when the asset list changes.
  • Python syncs only what nodes can't read: the camera's frame tangents (lens, sensor fit, shift, aspect). Camera movement needs no Python, because the tree reads the camera's transform.
  • Culling is conservative. The frustum slack is the instance's own radius × its scale, and the occlusion ray starts at the instance's top, so a visible tip is never removed.
  • Randomness is stable. Each decision has its own seed offset on the point ID, so toggling one feature doesn't reshuffle the others, and nothing pops while the camera moves.
  • A fix that mattered. For occlusion, objects that can't hide anything are tested as 12-triangle bounding boxes. That took a frame from about 100 s down to 1–2 s on 8 M triangles.
The tool

A scatter tool built for artists

Workflow

  • Select the asset LODs, then the ground, and click +. Files named *_LOD0, *_LOD1 and so on are grouped automatically.
  • Stack as many systems as you need. You can duplicate them, reorder them and toggle each one for viewport or render.
  • Save Preset stores the settings, the assets with their materials, and a rendered thumbnail. Add to Active Mesh rebuilds the preset anywhere, including a combined preset with several systems.

Look controls

  • Patches of noise for clumps and bare spots, which can also drive instance size.
  • Any curve in the Avoid collection becomes a path through the grass.
  • Align to ground, random tilt, and a global lean for wind-swept fields.
  • Dry grass in patches: one click wires per-instance hue and dryness into the materials.
